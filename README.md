# Uttarakhand Tourism Destination Recommendation System

This is my **second-year academic project** where I explored the fundamentals of **Machine Learning** and understood how ML algorithms work in real-world applications.

The project focuses on recommending tourism destinations in **Uttarakhand** based on user preferences and historical data. Through this project, I learned the complete workflow of a machine learning system — from data collection and preprocessing to model training and generating recommendations.
